# InvestGuard — 投资 Agent 质量治理 Demo

InvestGuard 用于持续评测、定位和改善投资 Agent 回答质量，重点覆盖答非所问、事实/数字错误、时效过期、个性化失真、合规越界和隐私风险。

> 本仓库是无依赖的交互式产品 Demo，不提供真实投资建议，也不连接真实用户、交易或行情系统。

## 快速运行

直接双击 `src/index.html`，或在仓库根目录执行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/src/`。Demo 不需要安装 npm 或 Python 依赖，也不会发起外部网络请求。

## 目标用户

- **质量运营**：配置评测、管理 BadCase、推动复核和回归。
- **模型与 Prompt 团队**：比较版本，定位幻觉、推理、切题和指令问题。
- **数据团队**：定位行情、知识库、检索、时点和来源异常。
- **KYC/策略团队**：维护画像字段、有效期、可信等级及适当性规则。
- **合规与隐私团队**：配置硬门槛、复核高风险样本、审计数据使用。
- **产品负责人**：判断候选版本是否达到灰度或发布条件。

## 四个产品入口

1. **总览**：查看整体质量、版本变化和优先风险。
2. **评测中心**：配置版本与场景，运行自动评测并执行发布门禁。
3. **问题闭环**：处理 BadCase 的发现、归因、人工复核和修复回归。
4. **治理中心**：统一管理质量标准、用户画像、适当性、热点时效、合规和隐私边界。

## 核心设计

### 1. 意图化评测

不同任务使用不同权重：行情查询关注数字和时点，热点解读关注新鲜度和事实/推断分离，产品比较关注同口径和完整性，个性化建议关注 KYC 与适当性，组合诊断关注计算和组合约束。

### 2. 三层回答架构

- **事实层**：行情、产品条款、法规、数学结果、来源和时间。
- **画像/适当性层**：目标、期限、流动性、风险意愿、损失能力和产品限制。
- **建议/表达层**：是否适合、备选路径、内容顺序和解释深度。

画像只能改变适当性和表达，不能改变客观事实。

### 3. 硬门槛优先

```text
最终通过 = 合规/隐私门禁通过
         AND 画像准入通过
         AND 意图质量分达标
         AND 关键维度不回退
```

关键事实错误、关键计算错误、过期信息冒充当前事实、重大适当性冲突、收益承诺或隐私泄露，不能被平均分抵消。

### 4. 可归因的版本比较

每次运行应记录模型、Prompt、数据快照、检索、KYC Schema、适当性策略、合规策略、Rubric 和 Judge 版本。单变量实验用于区分模型、Prompt、数据或策略增益。

## AI 在产品中的角色

AI 可以承担：

- 识别问答意图；
- 按 Rubric 判断切题、完整、解释和事实/观点分离；
- 聚类 BadCase 并提出候选归因；
- 合成画像缺失、冲突、热点和对抗场景；
- 生成供人工复核的摘要和修复建议。

AI 不可以承担：

- 充当行情、法规、产品条款或数学结果的最终事实源；
- 自行修改用户风险等级或机构产品匹配规则；
- 覆盖确定性计算、授权状态或合规硬门槛；
- 自动批准高风险版本发布；
- 根据点击、年龄、职业等弱信号擅自推断风险偏好。

自动评测负责规模与一致性，数据合演负责长尾覆盖，人工复核负责高风险裁决，用户行为只用于验证真实效用。

## 数据使用

当前 Demo：

- 全部指标、画像和 BadCase 均为静态合成数据；
- 不读取当前打开的报告、浏览器账户或本机个人文件；
- 不连接模型、行情、KYC、交易或第三方接口；
- 不上传或持久化任何用户输入；
- 导出报告仅由浏览器在本地生成。

生产化要求：

- 仅使用完成当前任务所必要的数据；
- KYC 字段必须包含来源、时间、可信等级、有效期和授权范围；
- 行为数据只能作为弱标签，不得直接决定适当性；
- 评测环境默认使用合成或脱敏 ID；
- 敏感字段应加密、字段级授权、可查询、更正、撤回和删除；
- 所有画像调用、模型版本、事实证据及人工修改必须可审计。

## 不可因画像改变的事实

以下内容对所有用户必须一致：同一时点的价格和净值、产品费率与合同条款、法律和交易规则、数学结果、来源原文与时间、不确定性以及已发生的风险事件。画像只允许改变适当性结论、表达深度、展示顺序和风险提示强度。

## 已知边界

- Demo 数据和评分均为演示值，不能用于真实模型发布决策；
- 所有状态仅保存在当前页面内，刷新后恢复；
- 模拟运行没有真实并发、成本、延迟和模型随机性；
- 当前没有真实 API、数据库、登录、权限和审计后端；
- 当前画像分级是产品设计示例，不代表任何机构的正式 KYC 标准；
- 当前没有对具体司法辖区法规和产品风险等级做正式映射；
- 静态 Demo 只能演示异常状态规范，不能实际触发网络故障。
